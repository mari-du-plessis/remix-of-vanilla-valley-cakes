# Remix of Vanilla Valley Cakes

Build a beautiful mobile-friendly cake ordering web app for Vanilla Valley bakery.



The app must include:

- A home page with cake images and a “Start Order” button

- A multi-step cake order form

- Occasion selection

- Cake size options

- Flavour options

- Filling options

- Extras checkboxes

- Inspiration photo upload

- Event date selector

- Budget field

- Customer contact details



After submission:

- Generate a WhatsApp message with all order details

- Mobile friendly

- Elegant feminine bakery style

- Soft neutral colors

- Easy to use for South African customers
